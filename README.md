# Natamata Optic — konsep demo SynergyDev
Bukan website resmi Natamata dan belum disetujui Natamata. Jangan dipublikasikan tanpa persetujuan.

Static HTML/CSS/JS tanpa build. Jalankan lokal:
```
python -m http.server 8080
```
Buka http://localhost:8080. Data produk dan cabang ada di bagian atas `assets/js/main.js`. Satu halaman dengan section anchor: Tentang, Koleksi, Layanan, Cabang, Kegiatan, Kontak.
